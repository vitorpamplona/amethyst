__TITLE__

doomgeneric on WebAssembly, played inside a Nostr napplet

Use the on-screen controls: the pad moves, FIRE shoots, USE opens doors. MENU, ENTER and YES drive the menus; a keyboard or gamepad works too.

Arrows move · Ctrl fire · Space open · Shift run · Alt/,. strafe · 1–7, [] weapons · Tab map · Esc menu. Gamepads work too.
